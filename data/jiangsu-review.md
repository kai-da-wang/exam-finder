# 江苏高校资料核验记录

核验日期：2026-09-23。新增 8 所学校、23 条资料、31 个文件链接；与此前南京大学的 6 条资料合计为江苏 9 校、21 门课程、29 条资料。

学校范围采用用户所称江苏“一本”高校的常见理解开展检索，不建立招生批次排名，不宣称全覆盖。江苏大学、南京师范大学等也进行过候选查找，但本批未发现足够明确、可直接核验的期末试卷，未添加空学校入口。

## 核验方法

通过 GitHub API 读取各仓库完整目录、确定提交及候选文件的完整二进制内容；对 base64 解码后的文件重算 Git blob SHA，与目录 SHA 逐项比对一致。PDF 解析全部页面文本，扫描页与字体编码异常页另行渲染查看；DOCX 读取正文 XML。明确学校、期末性质、课程版本、日期、题面完整性和答案关系后再加入审核清单。正文核查不代表逐题校对答案正确性，也不代表学校官方认证。

临时核验副本仅位于忽略目录 `.cache/jiangsu/`，网站只发布索引与固定到具体提交的 GitHub 文件链接，不发布试卷正文或本地副本。31 条新链接均有完整内容读取与 SHA 一致的核验证据；此前 70 条链接复用仍在 24 小时有效期内的同地址、同内容证据，未重写旧核验时间。
